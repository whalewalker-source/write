# Before Noon

A distraction-free writing page built around three rules:

1. Kill one precious idea or character, concretely and relatably.
2. Finish typing before 11:59am.
3. Land between 600 and 1000 words.

One file, no install, no dependencies. `index.html` is the whole app.

## Run it on a Mac

Fastest: double-click `index.html`. It opens in your browser. Press
`Cmd+Ctrl+F` for full screen and you have nothing on screen but the page.

Better: make it a dock app so it opens in its own window with no tabs or
address bar.

1. Open `index.html` in Safari.
2. File > Add to Dock.
3. Launch it from the Dock like any other app.

Chrome does the same thing under the three-dot menu > Cast, Save and Share >
Install page as app.

## What the three instruments do

**Upper left, the animal.** Rule 1. Each day picks a different living animal
emoji. Click it once when you have killed something precious and it becomes a
not symbol. Click it again when you are satisfied the death landed and it
becomes a checkmark. A third click brings the animal back if you change your
mind.

**Upper right, the clock.** Rule 2. Hours and minutes left until 11:59am
today, formatted `HH:MM`. At 11:59 it reads `00:00` and turns red for the rest
of the day. At midnight it resets.

**Lower right, the count.** Rule 3. Words still needed to reach 600. At 600 it
reads `0` and turns green, with your running total against the 1000 cap
underneath. Past 1000 it turns red and shows how far over you are.

## Where the writing lives

Each day gets its own blank page. Text saves automatically to the browser's
local storage as you type, so closing the window loses nothing. Yesterday's
page is not shown, but it is not gone either.

`Cmd+S` downloads today's page as a plain text file named by date. Do that
when you finish. Browser storage is per browser and per machine, and it is
not a backup.
